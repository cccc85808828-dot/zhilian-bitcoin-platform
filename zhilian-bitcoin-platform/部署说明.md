# 智链——比特币异常交易智能检测平台部署说明

## 部署范围

网站部署包提供比特币主网地址查询、关联交易自动研判、单笔交易证据分析和大模型解释。
前端为深蓝科技风的三页业务流程，智能助手在地址查询、关联交易和交易研判页面
保持一致。关联页通过Canvas绘制已载入交易的完整地址—交易有向网络，支持缩放、拖拽、
定位和跳转；研判页先从时间间隔、金额分布、输入输出角色、地址复用和手续费等可核验
事实识别多类可组合行为，再解释关联网络行为研判、单笔交易属性研判和综合结果，
不使用固定结论文本，
也不把风险分数本身表述为异常原因。

网站默认连接Blockstream Esplora，也可连接自建Esplora节点。服务端读取地址统计、
分页交易历史、确认状态、区块时间、输入输出、金额、手续费和交易大小，再构建地址—
交易动态超图并调用TTHGNN-QIF。结构分支沿用最终检查点，QIF部署适配器只使用公开
节点可重建的17项交易字段；其融合权重、分类阈值和0—100风险标尺仅在同口径验证集
上确定。部署包包含CPU推理需要的图检查点、QIF适配器和校准文件，不需要训练数据或
CUDA。

## Docker部署

1. 将 `.env.example` 复制为 `.env`。
2. 在服务端的 `.env` 中填写大模型API配置；不要把密钥写入前端代码。
3. 在项目根目录执行：

```bash
docker compose up --build -d
```

4. 访问 `http://服务器地址:8765`。

健康检查地址为 `/api/health`。部署到支持Docker的平台时，将容器端口设置为
`8765`；如平台自动提供 `PORT` 环境变量，程序会自动使用该端口。

不使用Docker时，可在Python 3.11环境中安装CPU依赖并直接启动：

```bash
python -m pip install --index-url https://download.pytorch.org/whl/cpu torch==2.5.1
python -m pip install numpy==2.0.1
python scripts/run_competition_demo.py --host 0.0.0.0 --port 8765 --no-browser
```

## 比特币主网数据

```text
BITCOIN_LIVE_ENABLED=1
BITCOIN_API_BASE_URL=https://blockstream.info/api
BITCOIN_API_TIMEOUT=20
BITCOIN_CACHE_TTL=300
BITCOIN_MAX_TRANSACTIONS=75
BITCOIN_MAX_PAGES=3
BITCOIN_MAX_ADDRESSES_PER_TX=256
BITCOIN_INFERENCE_DEVICE=cpu
```

- 公共Esplora接口无需浏览器端密钥，所有请求由服务端发起；
- 已确认交易每页25笔，`BITCOIN_MAX_TRANSACTIONS`和`BITCOIN_MAX_PAGES`共同限制
  单次查询规模；
- 页面会同时展示链上总笔数和本次已载入笔数，不把截断历史表述成全量结果；
- 正式公网部署建议把`BITCOIN_API_BASE_URL`切换为自建节点，以提升隐私、速率和
  可用性。

## 大模型助手

默认支持DeepSeek的Chat Completions API。将`.env.example`复制为`.env`
后填写服务端密钥；直接启动和Docker Compose都会读取该配置：

```text
DEEPSEEK_API_KEY=服务端密钥
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
LLM_PROVIDER=DeepSeek
```

也可使用 `LLM_API_KEY`、`LLM_MODEL` 和 `LLM_BASE_URL` 指向实现兼容
`/chat/completions` 接口的服务。配置后，浏览器会保留最近六条问答并随当前地址或交易证据
一同提交，实现可继续追问的多轮交互。没有配置密钥时，页面会明确显示“本地研判知识库”，
仍可根据结构分数、属性值、分支一致性和阈值距离生成动态回答，但不会冒充在线大模型。

大模型只接收压缩后的当前地址画像、所选交易模型分数、公开地址证据、系统生成的三层
判定依据及最近六条对话；它不参与分类，提示词要求其不得编造身份、链上事实或犯罪结论。
