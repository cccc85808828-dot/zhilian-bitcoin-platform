# 智链——比特币异常交易智能检测平台

智链是一套面向比特币链上交易研判的智能检测平台。平台以 TTHGNN-QIF 为核心方法，从地址查询出发，自动整理关联交易、输入输出角色、交易时间、资金金额与地址连接关系，并支持选择单笔交易查看关联网络行为、交易属性证据和综合研判结论。

平台提供两种运行方式。默认方式为无需外网和开发环境的离线演示，使用提前固化的近期比特币主网公开数据。在线方式可在具备 Python 环境和网络条件时连接 Esplora 接口查询其他主网地址。

风险指数用于表达模型研判强度，不等同于犯罪概率。系统只描述能够从公开链上记录核验的交易结构，不依据地址推断现实身份，也不直接作出违法犯罪事实认定。

## 1. 主要功能

- 地址查询：输入比特币地址后，载入其关联交易、交易时间、金额及输入输出角色。
- 关联网络：以地址和交易为节点展示有向连接，支持缩放、拖动、节点搜索和单笔交易跳转。
- 交易研判：分别展示关联网络行为研判、单笔交易属性研判和双分支融合结论。
- 证据解释：根据真实交易哈希、区块时间、输入输出数量、金额、手续费和模型分支结果生成可读说明。
- 智能助手：结合当前页面已经载入的证据回答技术原理、研判依据和报告生成类问题。

## 2. 核心方法

TTHGNN-QIF 由以下模块组成。

1. 角色感知时序交易超图。将地址表示为节点，将多输入多输出交易表示为带方向和输入输出角色的超边。
2. 双通道传播与地址记忆。分别聚合输入端和输出端信息，并保留地址跨时间行为状态。
3. 分位特征交互。对交易属性进行分位编码，通过二阶交互刻画金额、手续费、交易规模和输入输出数量等属性的联合关系。
4. 双分支风险融合。融合关联网络行为研判和单笔交易属性研判，在统一风险标尺上形成分类结果。
5. 稳健训练与解释。训练阶段使用跨环境风险约束和角色条件表征增强，解释阶段将模型证据映射为可核验的交易行为描述。

## 4. 实验协议

- 训练阶段：1—30。
- 验证阶段：31—35。
- 测试阶段：36—49。
- 随机种子：20260806、20260807、20260808、20260809、20260810。
- 早停依据：验证集平均精确率 AP。
- 融合权重与分类阈值：只在验证集上按 F1 最大原则确定。
- 未标注样本：不进入监督损失，也不生成非法伪标签。
- 测试集：只用于最终评价，不参与模型选择和阈值确定。

## 6. 一键离线演示

### 6.1 运行条件

- Windows 10 或 Windows 11。
- 系统自带 Windows PowerShell 5.1 或更高版本。
- Edge、Chrome 或其他现代浏览器。
- 不需要安装 Python、Node.js、Docker、数据库或模型运行环境。
- 不需要连接外网。

### 6.2 启动方法

双击根目录中的：

```text
启动竞赛演示.cmd
```

程序会启动本地离线服务并自动打开浏览器。默认地址为 `http://127.0.0.1:8765/`。如果该端口已被占用，程序会自动选择后续可用端口。关闭命令窗口即可停止服务。

### 6.3 预置近期真实地址

离线演示提供以下三个比特币主网公开地址。

| 示例 | 地址 | 结构说明 |
|---|---|---|
| 近期多笔归集 | `1DQgLuCsSvR2om2Z6Zk3u5ao6BvC9X1UCj` | 包含连续收转和多输入归集结构 |
| 近期扇出网络 | `bc1q0n4tyt8vtre84nhy7yy2ya3awlc9a94shxu4sl` | 单输入连接多输出的扇出结构 |
| 近期复杂换手 | `bc1qfj44gx27fgp00gv5f7htv2gwg89pprre9nqq5m` | 多输入、多输出及后续关联交易结构 |

建议依次完成以下操作。

1. 在地址查询页点击一个示例地址并开始查询。
2. 在关联交易页缩放或拖动网络，查看地址、交易和有向资金连接。
3. 从交易列表选择一笔交易进入交易研判页。
4. 查看交易事实、行为原因、关联网络证据、属性证据和综合结论。
5. 使用右下角智链助手追问研判依据或生成报告。

## 7. 在线研判模式

在线模式用于在具备网络和 Python 环境时查询其他比特币主网地址。运行：

```text
启动在线研判.cmd
```

在线模式读取 `.env` 中的服务端配置。密钥不会写入浏览器端代码。提交或共享项目时不得包含 `.env`，只保留不含真实密钥的 `.env.example`。

公网演示建议使用 `deploy/docker-compose.https.yml`，由 Caddy提供HTTPS证书和反向代理，
应用容器不直接暴露8765端口。公网部署还启用请求体限制、API限流、安全响应头和脱敏访问日志。
具体步骤见 `deploy/HTTPS部署说明.md`。

公开 Esplora 接口适合功能验证，持续部署建议使用自建节点并配置访问控制、缓存和限流。

## 8. 实验复现

按照 `environment.yml` 创建环境并准备 Elliptic++ 数据后，可执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/download_ellipticpp.ps1
python scripts/preprocess_ellipticpp.py --config configs/ellipticpp.yaml
python scripts/verify_ellipticpp.py
python scripts/run_final_experiments.py --stage check
```

运行主实验和消融实验：

```powershell
python scripts/run_final_experiments.py --stage main
```

根据已有结果重新汇总：

```powershell
python scripts/run_final_experiments.py --stage summarize
```

运行时间稳定性、灵敏度、效率和 PR 曲线分析：

```powershell
python scripts/run_final_experiments.py --stage analysis
```

六个扩展基线位于 `competition_baselines/`，包括 MDST-GNN、TFGAT-DCPLU、Elliptic++-HGT、FG-EGCN、GPN 和 NSGCN-LSTM。
